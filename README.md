Simple image converter with modern design

---

Open source, works 100% locally and available in web

Supports **`avif`**, **`bmp`**, **`exr`**, **`gif`**, **`jpg`**, **`jp2`**, **`j2k`**, **`jpm`**, **`j2c`**, **`jpc`**, **`jxl`**, **`png`**, **`tif`** and **`webp`**
